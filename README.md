# Projeto Obesidade - FIAP


Problema: Desenvolver um modelo de Machine Learning capaz de prever o nível de obesidade de um indivíduo com base em características físicas, hábitos alimentares e comportamentais, auxiliando a equipe médica na tomada de decisão.


## Tecnologias
- Python
- Scikit-Learn
- Streamlit
- Pandas
- Power BI

## Estrutura
- Bases/: Dados
- Projeto_Obesidade/: Código
- Models/: Modelo treinado
